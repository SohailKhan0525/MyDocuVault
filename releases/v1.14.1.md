### Close a preview while it opens

You can press Back while a shared Office document is still loading and return to the file actions. The reader keeps its private working copy until LibreOffice has finished, then removes it. Rotating during an import also waits for the complete file before opening it.

This patch includes the offline LibreOffice reader and illustrated onboarding introduced in v1.14.0. Install **MyDocuVault-v1.14.1.apk** over your existing copy to keep your vault.
